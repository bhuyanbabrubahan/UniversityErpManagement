# UMS Frontend ERP V2

Angular 19 + Angular Material 19 university ERP frontend with an enterprise responsive UI foundation and the existing authentication, student, faculty, profile, location and dashboard functionality preserved.

## Run

```bash
npm install
npm start
```

Open `http://localhost:4200`.

Development API requests use `/api` and are proxied by `proxy.conf.json` to `http://localhost:8089`.

## Production build

```bash
npm run build
```

See `docs/ERP-V2-ARCHITECTURE.md` for architecture and UI rules.
